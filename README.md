# 🐍 AP CSP Python Portfolio

Welcome to my **AP Computer Science Principles Portfolio**! This repository showcases a collection of Python applications developed during my second semester. These projects highlight my understanding of core computer science concepts, including data parsing, procedural abstraction, exception handling, and algorithmic design.

---

## 🚀 Projects Overview

### 🎮 Project 1: Pokémon Text Adventure Game
**Summary**: An interactive, text-based RPG where players train and manage a Pokémon over a series of days, guiding them through exercises, standard battles, and boss encounters. 
**Key Features**:
* **Evolutionary System**: Tracks XP milestones to automatically trigger evolutions (`Gastly` → `Haunter` → `Gengar`).
* **ASCII Art Engine**: Uses custom rendering logic to display detailed visual frames based on the active character.
* **Probability Mechanics**: Integrates RNG scaling to compute distinct win/loss constraints based on the Pokémon's current form.

---

### 🐕 Project 2: DogSite Breed Matcher (Create Task)
**Summary**: A data-driven search platform that analyzes user preferences to pair them with ideal dog breeds based on size, traits, and temperaments.
**Key Features**:
* **CSV Data Parsing**: Utilizes `pandas` to ingest and clean complex dataset arrays.
* **Linear Search Filtering**: Implements a locator algorithm to isolate matching text patterns from the data core.
* **Web Integration**: Leverages Python's native `webbrowser` library to dynamically launch breed images in the browser.

---

### 🦜 Project 3: Pet-Finder Assistant
**Summary**: A diagnostic decision tree that processes user inputs to recommend either domestic or exotic animal companions.
**Key Features**:
* **Nested Logic Trees**: Features deep conditional architectures to efficiently narrow down target categories.
* **Parallel Array Mapping**: Coordinates distinct description lists alongside indexed image resource arrays.

---

### 📝 Project 4: Interactive To-Do List Organizer
**Summary**: A sleek, terminal-based productivity utility allowing users to seamlessly maintain and track active daily tasks.
**Key Features**:
* **State Separation**: Maintains two independent live arrays concurrently for active and completed tasks.
* **Robust Input Validation**: Implements explicit `try/except` blocks to neutralize user index input crashes.
* **Full CRUD Routines**: Handles task additions, dynamic pointer deletions, and complete list resets smoothly.

---

### 🎰 Project 5: Terminal Slot Machine Simulator
**Summary**: A virtual casino simulation where users wager accumulated credits against randomized character matrices.
**Key Features**:
* **Wildcard Mechanics**: Evaluates special symbol strings (`☆`) to immediately trigger secondary free rolls.
* **High-Volume Stress Testing**: Contains a secret diagnostic mode (`1000`) that processes 1,000 automated iterations at once to report exact house yields.

---

### ✂️ Project 6: Rock, Paper, Scissors (with God Mode)
**Summary**: A command-line version of the classic game featuring a continuous lifetime session tracker against a randomized computer opponent.
**Key Features**:
* **Persistent Variables**: Safely mutates global counters across loops to record real-time wins, losses, and ties.
* **Hidden Developer Backdoor**: Contains an easter egg security key (`67234`) that unlocks an explicit "God Mode" to guarantee player victory.

---

### 🧩 Project 7: Wordle Game Engine (Create Task)
**Summary**: A text-based replica of the popular word game *Wordle*, testing user logic to identify hidden 5-letter strings in under six attempts.
**Key Features**:
* **Dual-File Matrix Validation**: Cross-checks user inputs against explicit valid guess lists and unique answer pools via external `.csv` matrices.
* **Positional Feedback Arrays**: Parses input strings down into granular character fragments to evaluate index match alignment and render visual feedback blocks (🟢, 🟡, 🔴).
